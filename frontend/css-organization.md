# CSS Organization

Review the repository's CSS organization and make necessary improvements so styles live in the appropriate files and follow the project's existing conventions.

Check for misplaced styles, oversized stylesheets, duplicated rules, inconsistent grouping, and component-specific styles that belong alongside their components. Keep shared styles, design tokens, and global defaults in clearly defined locations.

Before moving or consolidating styles, verify their usage and account for imports, cascade order, specificity, inheritance, and responsive overrides. Preserve the app's appearance and behavior, and avoid unrelated redesigns or introducing a new styling architecture.

Validate the affected screens at desktop and mobile sizes, run relevant checks, and summarize what changed and any remaining concerns.
