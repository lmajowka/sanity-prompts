# Accessibility Audit

Audit this app for accessibility issues against WCAG 2.2 AA. Inspect key screens and user flows using keyboard-only navigation, a screen reader or the accessibility tree, and both desktop and mobile viewports.

Check for missing or incorrect semantics, unlabeled controls, broken focus order, invisible or trapped focus, insufficient color contrast, missing text alternatives, inaccessible modals and menus, form errors that are not announced, content that relies only on color, motion without a reduced-motion alternative, and touch targets that are too small.

For each confirmed issue:
- Provide the screen or route, the affected element, and reproduction steps.
- Cite the WCAG success criterion it violates.
- Describe who is affected and how, and rate severity based on whether it blocks, hinders, or merely inconveniences users.
- Point to the responsible file and component, and recommend a concrete fix.

Distinguish confirmed failures verified in the running app from issues inferred only from source code. State which screens, tools, and assistive technologies you used, and note any testing limitations. Do not modify the app.
