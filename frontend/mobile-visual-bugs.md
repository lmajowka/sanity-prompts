# Mobile Visual Bug Hunt

Test the mobile version of this app for visual bugs. Inspect key screens and user flows at common mobile viewport sizes, including narrow screens.

Look for layout overflow, clipped or overlapping content, inconsistent spacing, unreadable text, misaligned elements, distorted images, and issues with navigation, forms, modals, and the on-screen keyboard. Check scrolling and interactive states where relevant.

For each confirmed bug:
- Provide the screen or route, viewport size, and reproduction steps.
- Describe the actual appearance and expected behavior.
- Include a screenshot when possible.
- Rate its severity based on user impact.

Distinguish reproducible bugs from subjective design preferences. State which screens and devices or simulated viewports you tested, and note any testing limitations. Do not modify the app.
