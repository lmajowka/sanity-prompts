# Backend Optimization Review

Review this repository for worthwhile backend optimizations. Examine database queries, API handlers, background jobs, caching, external service calls, and resource usage.

For each finding:
- Cite the relevant files and code paths.
- Explain the bottleneck or inefficiency and when it matters.
- Recommend a concrete improvement, including tradeoffs and risks.
- Describe how to measure the impact and verify correctness.

Prioritize by expected impact, confidence, and implementation effort. Distinguish confirmed issues from opportunities that require profiling or production metrics. Avoid speculative micro-optimizations, and preserve security, data integrity, and existing behavior.

Do not modify the repository. If no meaningful optimizations are supported by the evidence, say so.
